## Discovery

### What solo-founder products launched today?

**🔍 Signal**: [stagewise](https://www.producthunt.com/products/stagewise) (179 votes, Product Hunt #6) ships a coding agent that runs *inside its own sandboxed browser*, letting one-person teams test agent-generated UI flows without spinning up a separate Playwright rig.

The stagewise launch matters because the usual solo-founder tax — "I built the feature, now I have to set up Playwright + a test runner + a CI pipeline to verify it" — disappears when the agent owns the browser. Two other Product Hunt debuts reinforce the same pattern: [Resend CLI 2.0](https://www.producthunt.com/products/resend) (315 votes) explicitly markets itself as "humans + AI + CI/CD" and bakes GitHub Actions triggers into the command line, and [Astropad Workbench](https://www.producthunt.com/products/astropad) (110 votes) sells remote desktop access to headless Macs that are dedicated to running AI agents — a category that didn't exist six months ago.

On Reddit r/SideProject, a post titled "Got my first paying customer ($19) for a React Native boilerplate generator" documents day-by-day the three-week arc from landing page to first charge. The operator ran ads for $40, got zero signups, rewrote the demo video as a 30-second Loom, and converted the second visitor. The post-mortem is blunt: the demo was the product, not the code.

**Takeaway**: The 2026 indie wedge isn't "build a SaaS"; it's "ship an artifact that lets one person test, demo, or deploy without a team." Audit your onboarding today — if a new user needs you in the loop to see value, cut that dependency before adding features.

**Counter-view**: "Demo is the product" works for tools with a visual payoff; invisible infrastructure products still need a written case study to close.

**🔍 Signal**: [Claude Code Desktop App (Redesigned)](https://www.producthunt.com/products/claude-code) took #1 with 466 votes, but the more interesting entrant at #14 is [Agent Card](https://www.producthunt.com/products/agent-card) (112 votes) — a prepaid Visa card designed for AI agents, with per-merchant spend limits, auto-declines on unapproved domains, and webhook receipts.

The top 20 splits into three clean segments today. The middle contains Google's official [Gemini 3.1 Flash TTS](https://www.producthunt.com/products/gemini-flash-tts) (149) and [Subagents in Gemini CLI](https://www.producthunt.com/products/gemini-subagents) (140), plus [OpenAI Agents SDK](https://www.producthunt.com/products/openai-agents-sdk) (127). **Takeaway**: "Give AI agents bounded access to real systems" is a crossover category with three venture-backed entrants in one day. If you run agents against production APIs, pilot a card-based spend limit this week — even one false positive pays for a year.

**Counter-view**: Physical cards add mailing latency; software-only spend limits via Stripe Issuing already ship in 10 minutes and don't require a separate vendor.
